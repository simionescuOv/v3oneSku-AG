# AGENT INSTRUCTIONS

1. RESPONSE LANGUAGE: Always respond to the user in Romanian.
2. VERIFICATION MARKER: Start EVERY response with: "🟢 [GEMINI.MD ACTIV]".
3. READ-ONLY BY DEFAULT: Do not edit, create, or delete files without explicit confirmation.
4. CONFIRMATION PROTOCOL: If file edits are required, present a brief plan first and wait for approval (e.g., "Aprobat").
5. AUDIO TRANSCRIPTION PROTOCOL: Whenever the user sends a message via voice dictation / audio recording, start the response by displaying the exact audio transcription first.
6. LOCAL-FIRST ARCHITECTURE: The app operates Local-First for ultra-fast performance. Reads, page navigation, search, filtering, and detail views MUST operate 100% client-side from local Zustand memory (`useCatalogStore`). Never add network fetch/select calls on route navigation. Network calls are strictly reserved for user-triggered mutations (add/edit/delete).
7. DEV-PATH PRE-COMMIT PROTOCOL: ÎNAINTE de a executa comanda `git commit`, agentul are obligația să actualizeze `docs/dev-path.md` cu detaliile modificărilor (menționând obligatoriu și **Build Word-ul curent** activ în aplicație, pentru a identifica clar din ce ciclu de build face parte fiecare commit) și să adauge fișierul la `git add`, astfel încât codul și jurnalul de dezvoltare să fie incluse ÎNTR-UN SINGUR COMMIT unificat (fără commit-uri separate).
8. BUILD WORD & PUSH PROTOCOL: `git push` se execută EXCLUSIV la cererea expresă a utilizatorului (nu se face push automat după commit). La fiecare push solicitat, generează un cuvânt complet aleator din limba română care să NU aibă nicio similitudine tematică sau categorie comună cu cuvintele anterioare (este INTERZISĂ repetarea aceleiași tematici, ex: pietre prețioase, culori; cuvintele consecutive trebuie să provină din domenii complet necorelate — ex: *busola*, *castor*, *pendul*, *vulcan*). Actualizează `BUILD_WORD` în `src/pages/HomePage.jsx` și comunică cuvântul în răspuns pentru validarea versiunii live pe Vercel.
